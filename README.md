# ريناد دويدي للتصميم الداخلي — دليل الموقع

الموقع كله ملف واحد: `index.html`، ومعه مجلد الصور `images`.
كل المحتوى (النصوص، الأسعار، المشاريع، القطع، الروابط) موجود في **قسم واحد أعلى ملف `index.html`** عنوانه:

```
✏️  بيانات الموقع — عدّل هنا فقط
```

تعدّل هناك، والتصميم يتحدّث تلقائياً. **لا تلمس أي شي تحت سطر** `لا حاجة لتعديل ما تحت هذا السطر`.

---

## ١) محتويات المجلد

```
index.html                          ← الموقع كامل
README.md                           ← هذا الدليل
.nojekyll                           ← ملف مخفي يحتاجه GitHub Pages (لا تحذفه)
images/
├── about/
│   ├── renad.jpg                   ← صورة قسم «عن ريناد»
│   └── renad.png                   ← غلاف مشروع غرفة النوم
├── projects/
│   ├── project-01/Cover.png        ← غلاف مشروع ١ (+ صور المساحات لاحقاً)
│   ├── project-02/cover.jpeg
│   └── project-03/cover.jpeg
├── collection/
│   └── piece-01/
│       ├── cover.png               ← السرير
│       └── 2.png                   ← الكرسي
├── payments/                       ← شعارات وسائل الدفع (فاضي — ارفعها لاحقاً)
└── clients/                        ← شعارات الجهات (فاضي — اختياري)
```

> ملاحظة: GitHub ما يرفع المجلدات الفاضية. `payments` و`clients` بتظهر في المستودع أول ما تحط فيها ملف.

## ٣) رفع الموقع وتحديثه على GitHub

**أول مرة:**
1. Repository جديد **Public**.
2. Add file ← Upload files ← اسحب **محتويات** المجلد (`index.html` و`images` و`README.md` و`.nojekyll`) — مو المجلد نفسه.
3. Commit changes.
4. Settings ← Pages ← Deploy from a branch ← `main` و `(root)` ← Save.
5. بعد دقيقتين: `https://USERNAME.github.io/REPO/`

**التحديث:**
- تعديل نص أو رقم: افتح `index.html` في المستودع ← أيقونة القلم ✏️ ← عدّل ← Commit changes.
- صورة جديدة: افتح المجلد المطلوب في المستودع ← Add file ← Upload files.
- ملف بنفس الاسم يكتب فوق القديم.
- بعد أي تحديث: انتظر دقيقة أو دقيقتين، ثم حدّث الصفحة بـ `Ctrl + Shift + R`.

**الأسهل للتحديثات الكثيرة:** برنامج GitHub Desktop — تعدّل على جهازك ثم Commit ثم Push.

## ٤) قواعد الصور (مهم جداً)

- الاسم المكتوب في البيانات **يطابق اسم الملف حرفياً**، مع الامتداد: `Cover.png` غير `cover.png`.
- يفضّل أسماء إنجليزية بحروف صغيرة وبدون مسافات: `majlis-1.jpg`.
- الصيغ: `jpg` / `jpeg` / `png` / `webp`. صور الآيفون `HEIC` حوّلها لـ jpg أولاً.
- **الحجم:** حاول تكون الصورة أقل من ٥٠٠ كيلوبايت وعرضها حوالي ٢٠٠٠ بكسل. صور PNG الكبيرة (٢ ميقا وأكثر) تبطّئ الموقع على الجوال — حوّلها لـ jpg.
- الغلاف اللي يظهر في الواجهة الرئيسية لازم يكون **أفقي** وبجودة عالية.
- المسار يبدأ من مجلد المشروع/القطعة. إذا تبي صورة من مكان ثاني، اكتب المسار كامل يبدأ بـ `images/`.

## ٥) المشاريع وصور المساحات

كل مشروع في قائمة `projects`:

```js
{ title:"اسم المشروع", type:"سكني", area:"٢١٨ م²", city:"المدينة المنورة",
  folder:"project-01", cover:"Cover.png", photos:[], featured:true,
  text:"وصف المشروع",
  spaces: [
    { name:"المجلس",              photos:["majlis-1.jpg", "majlis-2.jpg"] },
    { name:"غرفة النوم الرئيسية", photos:["master-1.jpg"], note:"وصف اختياري" }
  ] },
```

- `folder`: اسم مجلد المشروع داخل `images/projects/`.
- `featured:true`: يظهر في العرض الرئيسي أعلى الموقع (يفضّل ٣ إلى ٥ مشاريع).
- `spaces`: صور المشروع مقسّمة حسب المساحات. **الصورة الناقصة تتجاهل، والمساحة الفاضية ما تظهر** — فتقدر تكتب المساحات الحين وترفع صورها بعدين.
- `before` / `after` (اختياري): صورتين لنفس الزاوية تظهر لها مقارنة بالسحب.
- **مشروع جديد:** انسخ قوس مشروع كامل `{ ... },` والصقه بعد آخر مشروع، وأنشئ مجلده.
- رابط مباشر لأي مشروع: `.../#p/project-01`

## ٦) قطع بتوقيع ريناد (المتجر)

**الأقسام** في `collection.categories` — بالترتيب اللي تظهر فيه:
`bedroom` غرف النوم · `wardrobes` الخزانات · `seating` الجلسات · `dining` طاولات الطعام · `tables` طاولات القهوة والجانبية · `entrance` المداخل والكونسول · `lighting` الإضاءة · `curtains` الستائر وملحقاتها · `decor` المرايا والديكور

- غيّر الترتيب بتقديم وتأخير الأسطر، أو أضف قسم بنفس الشكل.
- `showEmpty: true` ← الأقسام الفاضية تظهر ببطاقة «صمّم قطعتك». خلّها `false` لإخفائها.

**إضافة قطعة:**
1. مجلد جديد: `images/collection/wardrobe-01/` وفيه `cover.jpg` (طولية ٤:٥، خلفية سادة أفضل).
2. في `collection.pieces` انسخ قطعة وعدّلها:

```js
{ id:"wardrobe-01", name:"اسم القطعة", category:"wardrobes", price:"", payLink:"",
  cover:"cover.jpg", photos:["1.jpg"], leadTime:"٤ – ٦ أسابيع",
  materials:"الخامات", dimensions:"الأبعاد",
  text:"وصف القطعة",
  options:[ {label:"المقاس", values:["١٨٠ سم","٢٤٠ سم"]} ] },
```

- `id` = اسم المجلد بالضبط.
- `price`: رقم بالريال، أو `""` ليظهر «السعر حسب الطلب».
- `photos[0]`: تظهر عند مرور الماوس على البطاقة.
- **`payLink`** (رابط منتج في سلة أو رابط دفع من مُيسّر):
  - فاضي ← الطلب عبر واتساب + قائمة طلب تجمع أكثر من قطعة.
  - فيه رابط ← زر «اشتر الآن»: يرسل لك تفاصيل الخيارات والكمية على واتساب، ثم يفتح صفحة الدفع.
  - إذا استخدمت سلة: خلّ السعر نفسه في المكانين.
- رابط مباشر لأي قطعة: `.../#c/wardrobe-01`

## ٧) الاستشارة المدفوعة

```js
consultation: { price:500, payLink:"https://رابط-الدفع", includes:"زيارة موقع أو جلسة عن بُعد" },
```

- `price` يظهر في بطاقة جنب نموذج التواصل.
- `payLink`: بعد ما يرسل العميل طلب الاستشارة يظهر له زر «ادفع رسوم الاستشارة».
- فاضي ← الاستشارة طلب واتساب عادي.

## ٨) التوظيف والتدريب (يوصلك إيميل)

الطلبات تنرسل عبر خدمة **FormSubmit** المجانية مع السيرة الذاتية مرفقة.

1. اكتب بريدك في `careers.email`.
2. ارفع الملف، وقدّم **طلب تجريبي بنفسك** من الموقع.
3. بيوصلك إيميل تفعيل من FormSubmit ← اضغط الرابط.
4. من بعدها كل الطلبات توصلك. (أول طلب قبل التفعيل ما يوصل.)
5. اختياري: FormSubmit يعطيك عنوان بديل (رموز) — حطه مكان بريدك عشان ما يظهر في كود الموقع.

الوظائف وأنواع التدريب والنصوص كلها في `careers`. لإخفاء القسم: `enabled: false`.

> بيانات المتقدمين تمر على خوادم FormSubmit قبل ما توصلك.

## ١٠) وسائل الدفع والحساب البنكي (الفوتر)

- ارفع الشعارات الرسمية في `images/payments/` بالأسماء: `mada.svg` `visa.svg` `mastercard.svg` `applepay.svg` `stcpay.svg`.
  إذا كانت png غيّر الامتداد في `payments.methods`. الشعار الناقص يظهر مكانه الاسم مكتوب.
- احذف أي وسيلة مو مفعّلة فعلاً عندكم.
- الآيبان يظهر مقسّم مع زر «نسخ الآيبان». اتركه `""` لإخفاء بطاقة البنك.

## ١١) باقي الأقسام

| في البيانات | وش يتحكم فيه |
|---|---|
| `name` / `tagline` / `heroLine` | الاسم والعبارات (وتظهر في صفحة التحميل والفوتر) |
| `logo` | الشعار — اكتب `"images/logo.png"` بعد رفعه. يتحول أبيض فوق الصور تلقائياً |
| `about` | قسم «عن ريناد»: العنوان، الفقرات، التوقيع، بطاقة الخبرة، المبادئ |
| `services` | قائمة الخدمات |
| `steps` | مراحل العمل |
| `estimator` | حاسبة التكلفة — `unit:"m2"` بالمتر أو `"flat"` مبلغ ثابت، و`enabled:false` لإخفائها |
| `faq` | الأسئلة الشائعة |
| `hours` / `address` / `cr` | ساعات العمل، العنوان، السجل التجاري (اختياري) |

**صفحة التحميل:** تظهر مرة وحدة في كل زيارة. عشان تشوفها بعد تحديث، افتح الموقع في نافذة خاصة.

## ١٢) قواعد الكتابة في البيانات (عشان ما يخرب الموقع)

- كل نص بين علامتي تنصيص: `"نص"`.
- بعد كل عنصر فاصلة `,` — إلا آخر عنصر في القائمة (مسموح تبقيها بعد).
- لا تستخدم علامة `"` داخل النص. استخدم «» بدلها.
- الأرقام بدون تنصيص: `price:2400`.
- **إذا اختفى الموقع أو صار أبيض بعد تعديل:** غالباً نقصت فاصلة أو علامة تنصيص في آخر سطر عدّلته. ارجع للنسخة السابقة من History في GitHub.

## ١٣) حل المشاكل

| المشكلة | الحل |

## ١٤) دومين خاص (لاحقاً)

بعد شراء الدومين: Settings ← Pages ← Custom domain ← اكتب الدومين.
ثم من لوحة شركة الدومين أضف سجلات DNS اللي يعطيك إياها GitHub.
وبعدها حدّث رابط `og:image` بالدومين الجديد.
